# تعديل الإعلان — تنبيه إعادة المراجعة

عند تعديل إعلان قائم، يُعاد للإشراف. الواجهة تُنبّه المستخدم قبل الحفظ.

## الواجهة (`CreatePostCard` وضع `edit`)

1. **تنبيه ثابت** في بداية التعديل وفي خطوة الحفظ الأخيرة.
2. **مودال تأكيد** عند الضغط على «حفظ التعديلات».
3. بعد النجاح: toast يوضح أن الإعلان أُعيد للمراجعة (إن لم يكن المستخدم معتمداً للقبول التلقائي).
