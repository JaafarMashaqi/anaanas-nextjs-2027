# Implementation roadmap

Waves already in the local branch, not pushed:

1. Stability. Header no longer covers the homepage. Scroll stays at 0 on a fresh signed-out visit. Search tools sit inside the field.
2. Upper page. Greeting is stable. Stories stay above the Amman hero. One search on the home page.
3. Campaigns. Admin slider stays on its API. Invented brand slides are not in the greeting.
4. Pulse. Only counts the server actually returns are on the rail.

Still open, in this order:

1. City hierarchy, only when the country API exposes cities and listings can be filtered by them.
2. Search suggestions for a real query such as كامري, using existing listings. No invented volume.
3. Composer polish inside the current wizard. No second publisher.
4. Social card density, without fake engagement.
5. Turkish, French, Spanish, and Simplified Chinese dictionaries before any new routes.
6. Opportunity events only after a real auction-deadline or demand endpoint exists.

A production build was not run in this wave so the preview could stay up.
