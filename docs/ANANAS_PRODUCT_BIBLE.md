# ANANAS product bible

Status: founder baseline recorded from the current directive, checked against the original Next.js app at commit history through the local `main` tip. This file does not claim recovered chat history that is not in the repo.

## What ANANAS is

An Arabic-first social advertising operating system:

- A live social marketplace.
- An advertising and campaign platform, only where the promotion APIs exist.
- A supply-and-demand network. Wanted posts are not a server type yet.
- Social commerce. Reactions and comments exist. Stories, reels, and creators do not.
- Location-aware discovery limited to country and city. There is no nearby radius.
- Seller tools that already exist: listings, stores, auctions, my posts, promotion checkout.
- Trust UI only when a backend flag is present. No invented verification.

Philosophy: powerful product, calm interface, alive market.

Arabic line: السوق حي… والفرص تتحرك الآن.

## Hard rules

- Stay inside this Next.js app. Do not replace it.
- Laravel contracts stay. Do not invent metrics, search volume, demand, or sold counts.
- Do not add a second homepage or a second publisher.
- No GitHub push, publish, or deploy without founder approval.
- Preview stays on Turbopack. Do not run `next build` while the dev server is up.

## Phase order

0. Inventory. This document set.
1. Formatting, localization, and mobile structure that is already broken.
2. Design system. Navy, cloud, controlled gold. Not a yellow sheet.
3. Market Pulse from live counts. A drawer exists. Missing windows stay labeled missing.
4. Smart composer. One publisher. Advanced studio stays disconnected until an API exists.
5. Social cards. Real reactions, comments, price, and time.
6. Discovery, search, wanted, maps, matching. Foundations only where the server agrees.
7. Stories, reels, auctions presentation, live commerce, verified stores.
8. Seller center, memberships, campaigns.
9. Intelligence and opportunity engine. Rule-based versus API must stay labeled.
10. ANANAS Brain. Admin only. No public fake dashboard.

A phase is not complete because a decorative card exists.
